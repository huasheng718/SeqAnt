## Trellis 登记

沿用现有开发管理工作区的 `.trellis/`，不在产品仓重复初始化。父任务为 `11-23-public-mcp-visual-config`，包含 MCP-01 至 MCP-06 六个子任务；MCP-01 已进入 `in_progress`，其余任务按依赖保持 `planning`。任务仅在本地管理目录登记；本仓方案可独立审阅，不包含私有部署配置或凭据。

本包为内容的唯一维护来源；管理任务记录对应文档、依赖与验收入口。后续实施先核对实际 HEAD 与本基线的差异。

## 已确定的实施取舍

- 首期精选模板，官方全量 Registry 作为后续扩展。
- 项目与个人两种范围；保存配置不自动绑定角色或扩大任务权限。
- HTTP 从平台检查；stdio 首期在平台可用的独立 Docker 沙箱检查。独立 Runner 检查不新建调度协议，无可用能力时不展示为已支持。
- 检查结果首期只保留在当前页面会话，明确时间与测试位置；刷新后恢复“未测试”，不把一次成功作为持久健康证明。
- 候选目录不等于可发布目录。首期完整验收必须有真实 HTTP 和至少一个真实 stdio 模板证据。

最终视觉沿用根目录 `design.md` 的 SeqAnt / Harness 规范；灰度线框用于确认交互，不作为新的视觉规范。

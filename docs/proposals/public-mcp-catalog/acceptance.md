## 证据报告模板

每个真实实验记录：用例编号、执行时间、代码 SHA、镜像 / 包版本、操作者合成身份、作用域、测试位置、脱敏命令、退出码、结果文件、资源清理情况、失败 / 未验证项。

不得记录真实令牌、私有生产仓库内容或部署环境文件。本地实验数据仅使用自己创建的临时项目、用户和合成工作区。若当前环境无法完成某用例，列为未验证并保留原因，不改写通过标准。

## 放行条件

- E01–E25 的必要条件均有对应证据；任何缺失说明实际交付边界。
- 不少于一个真实 HTTP 和一个真实 stdio 服务通过本轮路径，原型模拟不能替代。
- 有当前 SHA 的必要领域 / handler / Repo / runtime / 前端回归及构建记录。
- 密钥、所有权、并发覆写、宿主机执行、资源清理和受控策略用例不得带着已知失败发布。
- 发布 / 推送不是方案完成的隐含动作；由用户后续指令授权。
